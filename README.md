# Multi-Camera Facial Recognition & Alert System

A Python-based experimental facial recognition project built with OpenCV. The goal of this project is to explore how real-time facial recognition systems work using local computer vision techniques and multi-camera processing.

## Features

- Real-time face detection
- Facial recognition using OpenCV LBPH
- Multi-camera support
- Watchlist-based alerts
- Windows desktop notifications
- Detection logging
- Dynamic face registration
- Offline/local processing

## Technologies

- Python
- OpenCV (`opencv-contrib-python`)
- NumPy
- Haar Cascade Classifiers
- LBPH Face Recognizer
- Threading
